# ed-mcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local stdio MCP server that gives Claude small tools for Elite Dangerous build planning: commander data (Inara, EDSM, Frontier CAPI), static game data (catalog), station and route search (Spansh), SLEF parsing, and a local plan store.

**Architecture:** TypeScript ESM package. One folder per data source under `src/`, each exporting a typed client with no MCP dependency. `src/tools/` is the only code that imports the MCP SDK; it registers tools on an `McpServer`. Clients take an injected `fetch` so tests never touch the network. Shipped as an npm package (`npx -y ed-mcp`) and a Claude Desktop `.mcpb` bundle.

**Tech Stack:** Node >= 22, TypeScript 7 (`tsc --noEmit` only), `@modelcontextprotocol/sdk` 1.32, `zod` 4, `tsup` 8 (bundling), `vitest` 5, `prettier` 3, `env-paths` 4, `@napi-rs/keyring` 2, `fastest-levenshtein` 1, `@anthropic-ai/mcpb` 2 (dev).

Spec: `docs/superpowers/specs/2026-10-11-ed-mcp-design.md`. Research notes: `docs/research/*.md`. Fixtures: `test/fixtures/<source>/`.

## Global Constraints

- Fixtures are recorded data and win over the plan: if a test's expected value conflicts with a fixture, correct the test value and say so in the commit message. Never edit fixtures to make a test pass.

- Node `>=22` in `engines`; CI matrix: `ubuntu-latest`, `macos-latest`, `windows-latest` × Node `22`, `24`.
- ESM only (`"type": "module"`); relative imports use the `.js` extension (NodeNext resolution).
- `tsc --noEmit` with `strict: true` must pass. No `any` in exported signatures.
- No network access in `npm test`. Every client takes `fetchFn: typeof fetch` through `HttpClient`.
- User-Agent on every request: `ed-mcp/<VERSION> (+https://github.com/pilotso11/ed-mcp)`.
- HTTP timeout 15 000 ms. One retry after 2 000 ms on network error, timeout or 5xx. No retry on 4xx.
- Cache TTLs: Inara and EDSM commander data 60 s, CAPI profile 60 s, Spansh 5 min.
- All service config optional. Unconfigured tool → error text `"<Service> not configured: set <VARS>"`.
- Tool output: compact JSON text (`JSON.stringify(value)`), lists default 10, `limit` max 50.
- Tool errors: `{ isError: true, content: [{ type: "text", text }] }`. Never return partial data as success.
- Paths: `envPaths("ed-mcp", { suffix: "" })` — `.config` for plans, `.cache` for catalog cache.
- Do not write anything to Inara. Only `getCommanderProfile` and `getCommunityGoalsRecent` are sent.
- Prettier defaults plus `printWidth: 100`. Comments explain why, not what.
- Commit after each task with a conventional message ending in
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```ts
/** Calls a tool and returns its first text block, parsed as JSON when possible. */
export async function callTool(
  client: Client,
  name: string,
  args: Record<string, unknown> = {},
): Promise<{ isError: boolean; text: string; json: unknown }> {
  const res = await client.callTool({ name, arguments: args });
  const content = res.content as Array<{ type: string; text?: string }>;
  const text = content[0]?.text ?? "";
  let json: unknown;
  try {
    json = JSON.parse(text);
  } catch {
    json = undefined;
  }
  return { isError: res.isError === true, text, json };
}
```

```ts
import path from "node:path";
import envPaths from "env-paths";
import { VERSION } from "./version.js";

export class ConfigError extends Error {
  override name = "ConfigError";
}

export interface InaraConfig {
  apiKey: string;
  cmdr: string;
  appName: string;
  devMode: boolean;
}
export interface EdsmConfig {
  apiKey: string;
  cmdr: string;
}
export interface CapiConfig {
  clientId: string;
}
export interface Config {
  inara?: InaraConfig;
  edsm?: EdsmConfig;
  capi?: CapiConfig;
  plansFile: string;
  cacheDir: string;
  userAgent: string;
}

type Env = Record<string, string | undefined>;

export function defaultDirs(): { config: string; cache: string } {
  const p = envPaths("ed-mcp", { suffix: "" });
  return { config: p.config, cache: p.cache };
}

// Claude Desktop passes "${user_config.x}" verbatim when an optional field has no value.
const UNSET_PLACEHOLDER = /^\$\{user_config\.[^}]+\}$/;

function get(env: Env, key: string): string | undefined {
  const v = env[key]?.trim();
  return v && !UNSET_PLACEHOLDER.test(v) ? v : undefined;
}

function bool(env: Env, key: string, fallback: boolean): boolean {
  const v = get(env, key)?.toLowerCase();
  if (v === undefined) return fallback;
  if (["1", "true", "yes"].includes(v)) return true;
  if (["0", "false", "no"].includes(v)) return false;
  throw new ConfigError(`${key} must be true or false, got "${env[key]}"`);
}

export function loadConfig(env: Env, dirs: { config: string; cache: string }): Config {
  const devMode = bool(env, "INARA_DEV_MODE", true);
  const inaraKey = get(env, "INARA_API_KEY");
  const inaraCmdr = get(env, "INARA_CMDR");
  const edsmKey = get(env, "EDSM_API_KEY");
  const edsmCmdr = get(env, "EDSM_CMDR");
  const capiClientId = get(env, "CAPI_CLIENT_ID");

  return {
    inara:
      inaraKey && inaraCmdr
        ? {
            apiKey: inaraKey,
            cmdr: inaraCmdr,
            appName: get(env, "INARA_APP_NAME") ?? "ed-mcp",
            devMode,
          }
        : undefined,
    edsm: edsmKey && edsmCmdr ? { apiKey: edsmKey, cmdr: edsmCmdr } : undefined,
    capi: capiClientId ? { clientId: capiClientId } : undefined,
    plansFile: get(env, "ED_MCP_PLANS") ?? path.join(dirs.config, "plans.json"),
    cacheDir: dirs.cache,
    userAgent: `ed-mcp/${VERSION} (+https://github.com/pilotso11/ed-mcp)`,
  };
}
```

**Interfaces:**
- Produces:
  - `type FetchFn = typeof fetch`
  - `class HttpError extends UserError { status?: number }`
  - `interface HttpClientOptions { userAgent: string; fetchFn?: FetchFn; timeoutMs?: number; retryDelayMs?: number }`
  - `class HttpClient { constructor(opts: HttpClientOptions); request(url: string, init?: RequestInit): Promise<Response>; json<T>(url: string, init?: RequestInit): Promise<T> }`
    - `request` adds User-Agent, applies timeout, retries once on network error/timeout/5xx, and returns the `Response` for any status (callers handle 304/4xx).
    - `json` calls `request`, throws `HttpError` on non-2xx (message `"<host> returned HTTP <status>"`), parses JSON (throws `HttpError` `"<host> returned invalid JSON"`).
  - `interface CacheStats { name: string; entries: number; oldestAgeSeconds: number | null }`
  - `interface Clearable { readonly name: string; clear(): number; stats(): CacheStats }`
  - `class TtlCache<V> implements Clearable { constructor(name: string, ttlMs: number, now?: () => number); get(key: string): V | undefined; set(key: string, value: V): void; getOrLoad(key: string, load: () => Promise<V>): Promise<V>; clear(): number; stats(): CacheStats }`
    - `getOrLoad` shares one in-flight promise per key; a rejected load is not cached.
  - `class CacheRegistry { register(c: Clearable): void; names(): string[]; clear(name: string): number; clearAll(): Record<string, number>; stats(): CacheStats[] }`
  - Test helper `fakeFetch(routes: FakeRoute[]): FetchFn & { calls: FakeCall[] }` where `FakeRoute = { match: (url: string, init?: RequestInit) => boolean; respond: (url: string, init?: RequestInit) => Response | Promise<Response> }` and `FakeCall = { url: string; init?: RequestInit }`; unmatched requests throw `Error("unexpected fetch: <url>")`. Also `jsonResponse(body: unknown, status = 200, headers: Record<string,string> = {}): Response`.

```ts
import type { FetchFn } from "../../src/http/client.js";

export interface FakeCall {
  url: string;
  init?: RequestInit;
}
export interface FakeRoute {
  match: (url: string, init?: RequestInit) => boolean;
  respond: (url: string, init?: RequestInit) => Response | Promise<Response>;
}

export function fakeFetch(routes: FakeRoute[]): FetchFn & { calls: FakeCall[] } {
  const calls: FakeCall[] = [];
  const fn = async (input: string | URL | Request, init?: RequestInit): Promise<Response> => {
    const url = typeof input === "string" ? input : input instanceof URL ? input.href : input.url;
    calls.push({ url, init });
    const route = routes.find((r) => r.match(url, init));
    if (!route) throw new Error(`unexpected fetch: ${url}`);
    return route.respond(url, init);
  };
  return Object.assign(fn as FetchFn, { calls });
}

export function jsonResponse(
  body: unknown,
  status = 200,
  headers: Record<string, string> = {},
): Response {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "content-type": "application/json", ...headers },
  });
}

/** Reads a JSON fixture from test/fixtures. */
export async function fixture<T = unknown>(rel: string): Promise<T> {
  const { readFile } = await import("node:fs/promises");
  const url = new URL(`../fixtures/${rel}`, import.meta.url);
  return JSON.parse(await readFile(url, "utf8")) as T;
}
```

```ts
import { UserError } from "../errors.js";

export type FetchFn = typeof fetch;

export class HttpError extends UserError {
  override name = "HttpError";
  constructor(
    message: string,
    readonly status?: number,
  ) {
    super(message);
  }
}

export interface HttpClientOptions {
  userAgent: string;
  fetchFn?: FetchFn;
  timeoutMs?: number;
  retryDelayMs?: number;
}

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

export class HttpClient {
  private readonly fetchFn: FetchFn;
  private readonly timeoutMs: number;
  private readonly retryDelayMs: number;

  constructor(private readonly opts: HttpClientOptions) {
    this.fetchFn = opts.fetchFn ?? fetch;
    this.timeoutMs = opts.timeoutMs ?? 15_000;
    this.retryDelayMs = opts.retryDelayMs ?? 2_000;
  }

  async request(url: string, init: RequestInit = {}): Promise<Response> {
    try {
      const res = await this.once(url, init);
      if (res.status < 500) return res;
    } catch {
      // fall through to the single retry
    }
    await sleep(this.retryDelayMs);
    return this.once(url, init).catch((err: unknown) => {
      throw this.wrap(url, err);
    });
  }

  async json<T>(url: string, init: RequestInit = {}): Promise<T> {
    const host = new URL(url).host;
    const res = await this.request(url, init);
    if (!res.ok) throw new HttpError(`${host} returned HTTP ${res.status}`, res.status);
    try {
      return (await res.json()) as T;
    } catch {
      throw new HttpError(`${host} returned invalid JSON`, res.status);
    }
  }

  private async once(url: string, init: RequestInit): Promise<Response> {
    const headers = new Headers(init.headers);
    headers.set("user-agent", this.opts.userAgent);
    const signal = AbortSignal.timeout(this.timeoutMs);
    return this.fetchFn(url, { ...init, headers, signal });
  }

  private wrap(url: string, err: unknown): HttpError {
    const host = new URL(url).host;
    if (err instanceof DOMException && err.name === "TimeoutError") {
      return new HttpError(`${host}: timed out after ${this.timeoutMs} ms`);
    }
    return new HttpError(`${host}: ${err instanceof Error ? err.message : String(err)}`);
  }
}
```

`src/http/cache.ts`:
```ts
export interface CacheStats {
  name: string;
  entries: number;
  oldestAgeSeconds: number | null;
}

export interface Clearable {
  readonly name: string;
  clear(): number;
  stats(): CacheStats;
}

interface Entry<V> {
  value: V;
  storedAt: number;
}

export class TtlCache<V> implements Clearable {
  private readonly entries = new Map<string, Entry<V>>();
  private readonly inflight = new Map<string, Promise<V>>();

  constructor(
    readonly name: string,
    private readonly ttlMs: number,
    private readonly now: () => number = Date.now,
  ) {}

  get(key: string): V | undefined {
    const e = this.entries.get(key);
    if (!e) return undefined;
    if (this.now() - e.storedAt >= this.ttlMs) {
      this.entries.delete(key);
      return undefined;
    }
    return e.value;
  }

  set(key: string, value: V): void {
    this.entries.set(key, { value, storedAt: this.now() });
  }

  async getOrLoad(key: string, load: () => Promise<V>): Promise<V> {
    const hit = this.get(key);
    if (hit !== undefined) return hit;
    const pending = this.inflight.get(key);
    if (pending) return pending;
    const p = load()
      .then((v) => {
        this.set(key, v);
        return v;
      })
      .finally(() => this.inflight.delete(key));
    this.inflight.set(key, p);
    return p;
  }

  clear(): number {
    const n = this.entries.size;
    this.entries.clear();
    return n;
  }

  stats(): CacheStats {
    for (const k of [...this.entries.keys()]) this.get(k); // drop expired entries
    let oldest: number | null = null;
    for (const e of this.entries.values()) {
      if (oldest === null || e.storedAt < oldest) oldest = e.storedAt;
    }
    return {
      name: this.name,
      entries: this.entries.size,
      oldestAgeSeconds: oldest === null ? null : Math.floor((this.now() - oldest) / 1000),
    };
  }
}

export class CacheRegistry {
  private readonly caches = new Map<string, Clearable>();

  register(c: Clearable): void {
    this.caches.set(c.name, c);
  }

  names(): string[] {
    return [...this.caches.keys()];
  }

  clear(name: string): number {
    const c = this.caches.get(name);
    if (!c) throw new Error(`Unknown cache "${name}"`);
    return c.clear();
  }

  clearAll(): Record<string, number> {
    return Object.fromEntries([...this.caches].map(([n, c]) => [n, c.clear()]));
  }

  stats(): CacheStats[] {
    return [...this.caches.values()].map((c) => c.stats());
  }
}
```

```ts
import type { CallToolResult } from "@modelcontextprotocol/sdk/types.js";
import { UserError } from "../errors.js";

export function ok(value: unknown): CallToolResult {
  return { content: [{ type: "text", text: JSON.stringify(value) }] };
}

export function fail(message: string): CallToolResult {
  return { isError: true, content: [{ type: "text", text: message }] };
}

export function wrap<A>(fn: (args: A) => Promise<unknown>): (args: A) => Promise<CallToolResult> {
  return async (args: A) => {
    try {
      return ok(await fn(args));
    } catch (err) {
      if (err instanceof UserError) return fail(err.message);
      console.error(err);
      return fail(`Internal error: ${err instanceof Error ? err.message : String(err)}`);
    }
  };
}
```

```ts
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { z } from "zod";
import { UserError } from "../errors.js";
import type { CacheRegistry } from "../http/cache.js";
import { wrap } from "./result.js";

export interface Refreshable {
  readonly name: string;
  refresh(): Promise<unknown>;
  status(): unknown;
}

export function registerCacheTools(
  server: McpServer,
  deps: { caches: CacheRegistry; refreshables?: Refreshable[] },
): void {
  const refreshables = deps.refreshables ?? [];

  server.registerTool(
    "cache_refresh",
    {
      description:
        "Clear cached data so the next call fetches fresh data. source: a source name or 'all' (default). " +
        "For 'catalog' this also checks upstream for new game data.",
      inputSchema: { source: z.string().optional() },
    },
    wrap(async ({ source = "all" }: { source?: string }) => {
      const valid = ["all", ...deps.caches.names(), ...refreshables.map((r) => r.name)];
      if (!valid.includes(source)) {
        throw new UserError(`Unknown source "${source}". Valid: ${valid.join(", ")}`);
      }
      const out: { cleared?: Record<string, number>; refreshed?: Record<string, unknown> } = {};
      if (source === "all") {
        out.cleared = deps.caches.clearAll();
        if (refreshables.length) {
          out.refreshed = {};
          for (const r of refreshables) out.refreshed[r.name] = await r.refresh();
        }
        return out;
      }
      const r = refreshables.find((x) => x.name === source);
      if (r) return { refreshed: { [r.name]: await r.refresh() } };
      return { cleared: { [source]: deps.caches.clear(source) } };
    }),
  );

  server.registerTool(
    "cache_status",
    { description: "Show cached entries and their age per source, and catalog version." },
    wrap(async () => ({
      caches: deps.caches.stats(),
      refreshables: Object.fromEntries(refreshables.map((r) => [r.name, r.status()])),
    })),
  );
}
```

```ts
import { mkdir, readFile, rename, writeFile } from "node:fs/promises";
import path from "node:path";
import { z } from "zod";
import { UserError } from "../errors.js";
import {
  PlanFileSchema,
  PlanInputSchema,
  type Plan,
  type PlanFile,
  type PlanInput,
  type PlanItem,
} from "./schema.js";

export interface PlanSummary {
  id: string;
  name: string;
  items: number;
  done: number;
  updated_at: string;
}

export class PlanStore {
  private queue: Promise<unknown> = Promise.resolve();

  constructor(
    private readonly file: string,
    private readonly now: () => Date = () => new Date(),
  ) {}

  async list(): Promise<PlanSummary[]> {
    const { plans } = await this.read();
    return plans.map((p) => ({
      id: p.id,
      name: p.name,
      items: p.items.length,
      done: p.items.filter((i) => i.status === "done" || i.status === "skipped").length,
      updated_at: p.updated_at,
    }));
  }

  async get(id: string): Promise<Plan> {
    const plan = (await this.read()).plans.find((p) => p.id === id);
    if (!plan) throw new UserError(`Plan "${id}" not found`);
    return plan;
  }

  upsert(input: PlanInput): Promise<Plan> {
    return this.mutate((data) => {
      const parsed = PlanInputSchema.safeParse(input);
      if (!parsed.success) throw new UserError(`Invalid plan: ${z.prettifyError(parsed.error)}`);
      const stamp = this.now().toISOString();
      const idx = data.plans.findIndex((p) => p.id === parsed.data.id);
      const plan: Plan = {
        ...parsed.data,
        created_at: idx >= 0 ? data.plans[idx]!.created_at : stamp,
        updated_at: stamp,
      };
      if (idx >= 0) data.plans[idx] = plan;
      else data.plans.push(plan);
      return plan;
    });
  }

  updateItem(
    planId: string,
    itemId: string,
    patch: { status?: PlanItem["status"]; notes?: string },
  ): Promise<Plan> {
    return this.mutate((data) => {
      const plan = data.plans.find((p) => p.id === planId);
      if (!plan) throw new UserError(`Plan "${planId}" not found`);
      const item = plan.items.find((i) => i.id === itemId);
      if (!item) throw new UserError(`Item "${itemId}" not found in plan "${planId}"`);
      if (patch.status !== undefined) item.status = patch.status;
      if (patch.notes !== undefined) item.notes = patch.notes;
      plan.updated_at = this.now().toISOString();
      return plan;
    });
  }

  async delete(id: string): Promise<void> {
    await this.mutate((data) => {
      const idx = data.plans.findIndex((p) => p.id === id);
      if (idx < 0) throw new UserError(`Plan "${id}" not found`);
      data.plans.splice(idx, 1);
    });
  }

  private async read(): Promise<PlanFile> {
    let raw: string;
    try {
      raw = await readFile(this.file, "utf8");
    } catch (err) {
      if ((err as NodeJS.ErrnoException).code === "ENOENT") return { version: 1, plans: [] };
      throw err;
    }
    let json: unknown;
    try {
      json = JSON.parse(raw);
    } catch {
      throw new UserError(`Plan file ${this.file} is invalid: not JSON`);
    }
    const parsed = PlanFileSchema.safeParse(json);
    if (!parsed.success) {
      throw new UserError(`Plan file ${this.file} is invalid: ${z.prettifyError(parsed.error)}`);
    }
    return parsed.data;
  }

  // Read-modify-write runs one at a time so concurrent tool calls cannot lose updates.
  private mutate<T>(fn: (data: PlanFile) => T): Promise<T> {
    const run = this.queue.then(async () => {
      const data = await this.read();
      const result = fn(data);
      await mkdir(path.dirname(this.file), { recursive: true });
      const tmp = `${this.file}.${process.pid}.tmp`;
      await writeFile(tmp, JSON.stringify(data, null, 2));
      await rename(tmp, this.file);
      return result;
    });
    this.queue = run.catch(() => undefined);
    return run;
  }
}
```

```ts
import type { Plan, PlanItem } from "./schema.js";

const box: Record<PlanItem["status"], string> = {
  todo: "[ ]",
  in_progress: "[~]",
  done: "[x]",
  skipped: "[-]",
};

export function planToMarkdown(plan: Plan): string {
  const done = plan.items.filter((i) => i.status === "done" || i.status === "skipped").length;
  const out = [
    `# ${plan.name}`,
    "",
    `Plan \`${plan.id}\` · updated ${plan.updated_at} · ${done}/${plan.items.length} done`,
    "",
  ];
  if (plan.notes) out.push(plan.notes, "");
  if (plan.items.length) {
    out.push("## Items", "");
    for (const i of plan.items) {
      const where = [
        i.station ? `at ${i.station}` : undefined,
        i.engineer ? `engineer ${i.engineer}` : undefined,
      ].filter(Boolean);
      out.push(`- ${box[i.status]} **${i.kind}** ${i.description}${where.length ? ` — ${where.join(", ")}` : ""}`);
      if (i.materials?.length) {
        out.push(`  - Materials: ${i.materials.map((m) => `${m.count}× ${m.name}`).join(", ")}`);
      }
      if (i.notes) out.push(`  - Notes: ${i.notes}`);
    }
    out.push("");
  }
  if (plan.stops.length) {
    out.push("## Route", "");
    plan.stops.forEach((s, n) => {
      out.push(`${n + 1}. ${s.system}${s.station ? ` — ${s.station}` : ""}: ${s.purpose}`);
    });
    out.push("");
  }
  return out.join("\n");
}
```

```ts
import { mkdir, writeFile } from "node:fs/promises";
import path from "node:path";
import type { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { z } from "zod";

import { ItemStatus, PlanInputSchema, type PlanInput } from "../plans/schema.js";

import { wrap } from "./result.js";

export function registerPlanTools(server: McpServer, deps: { plans: PlanStore }): void {
  const { plans } = deps;

  server.registerTool(
    "plan_list",
    { description: "List saved build plans with item counts and progress." },
    wrap(async () => plans.list()),
  );

  server.registerTool(
    "plan_get",
    { description: "Get a saved plan by id.", inputSchema: { id: z.string() } },
    wrap(async ({ id }: { id: string }) => plans.get(id)),
  );

  server.registerTool(
    "plan_upsert",
    {
      description:
        "Create or replace a build plan. Items are things to buy, engineer, unlock, gather or trade; " +
        "stops are the route. Replacing keeps created_at.",
      inputSchema: { plan: PlanInputSchema },
    },
    wrap(async ({ plan }: { plan: PlanInput }) => plans.upsert(plan)),
  );

  server.registerTool(
    "plan_update_item",
    {
      description: "Set the status and/or notes of one plan item.",
      inputSchema: {
        plan_id: z.string(),
        item_id: z.string(),
        status: ItemStatus.optional(),
        notes: z.string().optional(),
      },
    },
    wrap(
      async (a: {
        plan_id: string;
        item_id: string;
        status?: z.infer<typeof ItemStatus>;
        notes?: string;
      }) => plans.updateItem(a.plan_id, a.item_id, { status: a.status, notes: a.notes }),
    ),
  );

  server.registerTool(
    "plan_delete",
    { description: "Delete a saved plan.", inputSchema: { id: z.string() } },
    wrap(async ({ id }: { id: string }) => {
      await plans.delete(id);
      return { deleted: id };
    }),
  );

  server.registerTool(
    "plan_export",
    {
      description:
        "Export a plan as Markdown. Without path, returns the Markdown. With path, writes the file.",
      inputSchema: { id: z.string(), path: z.string().optional() },
    },
    wrap(async (a: { id: string; path?: string }) => {
      const markdown = planToMarkdown(await plans.get(a.id));
      if (!a.path) return { markdown };
      const target = path.resolve(a.path);
      await mkdir(path.dirname(target), { recursive: true });
      await writeFile(target, markdown);
      return { path: target, bytes: Buffer.byteLength(markdown) };
    }),
  );
}
```

```ts
import type { EdsmConfig } from "../config.js";
import { NotConfiguredError, UserError } from "../errors.js";
import type { TtlCache } from "../http/cache.js";
import type { HttpClient } from "../http/client.js";

export interface EdsmPosition {
  system: string | null;
  coordinates: { x: number; y: number; z: number } | null;
  docked: boolean | null;
  station: string | null;
  ship: string | null;
  lastSeen: string | null;
  profileUrl: string | null;
}

export interface EdsmItem {
  symbol: string;
  name: string;
  count: number;
}

export type InventoryKind = "materials" | "data" | "cargo";

interface Envelope {
  msgnum: number;
  msg: string;
  [key: string]: unknown;
}

interface RawPosition extends Envelope {
  system?: string | null;
  coordinates?: { x: number; y: number; z: number } | null;
  isDocked?: boolean | null;
  station?: string | null;
  shipType?: string | null;
  date?: string | null;
  dateLastActivity?: string | null;
  url?: string | null;
}

export class EdsmClient {
  constructor(
    private readonly http: HttpClient,
    private readonly cfg: EdsmConfig | undefined,
    private readonly cache: TtlCache<unknown>,
    private readonly baseUrl = "https://www.edsm.net",
  ) {}

  async position(): Promise<EdsmPosition> {
    const raw = (await this.call("api-logs-v1/get-position", { showCoordinates: "1" })) as RawPosition;
    return {
      system: raw.system ?? null,
      coordinates: raw.coordinates ?? null,
      docked: raw.isDocked ?? null,
      station: raw.station ?? null,
      ship: raw.shipType ?? null,
      lastSeen: raw.date ?? raw.dateLastActivity ?? null,
      profileUrl: raw.url ?? null,
    };
  }

  async inventory(kinds: InventoryKind[]): Promise<Partial<Record<InventoryKind, EdsmItem[]>>> {
    const out: Partial<Record<InventoryKind, EdsmItem[]>> = {};
    for (const kind of kinds) {
      const raw = await this.call("api-commander-v1/get-materials", { type: kind });
      const items = (raw[kind] ?? []) as Array<{ type: string; name: string; qty: number }>;
      out[kind] = items.map((i) => ({ symbol: i.type, name: i.name, count: i.qty }));
    }
    return out;
  }

  private async call(endpoint: string, params: Record<string, string>): Promise<Envelope> {
    const cfg = this.cfg;
    if (!cfg) throw new NotConfiguredError("EDSM", ["EDSM_API_KEY", "EDSM_CMDR"]);
    const url = new URL(`${this.baseUrl}/${endpoint}`);
    url.search = new URLSearchParams({
      commanderName: cfg.cmdr,
      apiKey: cfg.apiKey,
      ...params,
    }).toString();
    const body = (await this.cache.getOrLoad(url.href, () =>
      this.http.json<Envelope>(url.href).then((b) => {
        // Throw before caching so errors are retried on the next call.
        check(b);
        return b;
      }),
    )) as Envelope;
    return body;
  }
}

function check(b: Envelope): void {
  if (b.msgnum === 100) return;
  if (b.msgnum === 203) {
    throw new UserError(
      "EDSM: commander name or API key not found. Check EDSM_CMDR and EDSM_API_KEY, and that EDSM sync is on in EDMC.",
    );
  }
  throw new UserError(`EDSM error ${b.msgnum}: ${b.msg}`);
}
```

Note: `url.href` includes the API key; it is only used as an in-memory cache key and is never logged or returned.

Background (see `docs/research/spansh.md`): base `https://spansh.co.uk/api`, no auth. Errors are `{"error": "..."}` with 4xx. `id64` values can exceed 2^53, so they are quoted to strings before `JSON.parse`. Station search is `POST /api/stations/search`; results carry huge `market`/`modules`/`ships` arrays that must be stripped. Ship names must be resolved against `GET /api/stations/field_values/ships` (`"Python MkII"`, but `"Kestrel Mk II"`). An unknown `reference_system` gives HTTP 400 `{"error":"Invalid request"}`. `count` caps at 10000. Routes: `POST /api/route` (form-encoded) → 202 `{job}`; poll `GET /api/results/<job>`: 202 = still running, 200 with `status: "ok"` = done, 404 = unknown job.

**Interfaces:**
- Consumes: `HttpClient` (Task 3), `TtlCache` (Task 3), `UserError` (Task 2), `wrap` (Task 4).
- Produces:
  - `parseSpanshJson(text: string): unknown` — quotes every `"id64"`/`"system_id64"`/`"id"` integer value with 16+ digits as a string, then parses.
  - `type StationService = "material_trader_raw" | "material_trader_manufactured" | "material_trader_encoded" | "tech_broker_human" | "tech_broker_guardian" | "interstellar_factors"`
  - `interface StationQuery { near: string; module?: { name: string; class?: number; rating?: string }; ship?: string; service?: StationService; largePad?: boolean; maxDistanceLy?: number; limit: number }`
  - `interface StationHit { name: string; system: string; distance_ly: number; arrival_ls: number | null; type: string | null; pad: "L" | "M" | "S" | null; planetary: boolean | null; price: number | null; market_updated_at: string | null; outfitting_updated_at: string | null; shipyard_updated_at: string | null }`
  - `interface StationResult { near: string; total: number; total_capped: boolean; stations: StationHit[] }`
  - `interface SystemInfo { name: string; id64: string; coords: { x: number; y: number; z: number }; allegiance: string | null; government: string | null; security: string | null; population: number | null; needs_permit: boolean | null; stations: Array<{ name: string; type: string | null; arrival_ls: number | null; pad: "L" | "M" | "S" | null; market: boolean; outfitting: boolean; shipyard: boolean; services: string[] }>; station_count: number }`
  - `interface RouteQuery { from: string; to: string; rangeLy: number; efficiency?: number; supercharge?: "neutron" | "overcharge" }`
  - `interface RouteResult { from: string; to: string; distance_ly: number; total_jumps: number; waypoints: Array<{ system: string; jumps: number; distance_jumped_ly: number; distance_left_ly: number; neutron: boolean }> }`
  - `class SpanshClient { constructor(http: HttpClient, cache: TtlCache<unknown>, opts?: { baseUrl?: string; minIntervalMs?: number; sleep?: (ms: number) => Promise<void>; routeTimeoutMs?: number }); findStations(q: StationQuery): Promise<StationResult>; system(name: string, stationLimit: number): Promise<SystemInfo>; route(q: RouteQuery): Promise<RouteResult>; resolveShip(name: string): Promise<string> }`
    - Requests are spaced at least `minIntervalMs` (default 1000) apart.

  - `ServerDeps` gains `spansh?: SpanshClient`. `buildDeps` creates it with `TtlCache("spansh", 300_000)` registered.

```ts
// Body and station ids can exceed 2^53, which JSON.parse rounds silently.
const BIG_ID = /("(?:id64|system_id64|id)"\s*:\s*)(\d{16,})/g;

export function parseSpanshJson(text: string): unknown {
  return JSON.parse(text.replace(BIG_ID, '$1"$2"'));
}
```

```ts
import { UserError } from "../errors.js";
import type { TtlCache } from "../http/cache.js";
import type { HttpClient } from "../http/client.js";
import { parseSpanshJson } from "./json.js";

export type StationService =
  | "material_trader_raw"
  | "material_trader_manufactured"
  | "material_trader_encoded"
  | "tech_broker_human"
  | "tech_broker_guardian"
  | "interstellar_factors";

export interface StationQuery {
  near: string;
  module?: { name: string; class?: number; rating?: string };
  ship?: string;
  service?: StationService;
  largePad?: boolean;
  maxDistanceLy?: number;
  limit: number;
}

type Pad = "L" | "M" | "S" | null;

export interface StationHit {
  name: string;
  system: string;
  distance_ly: number;
  arrival_ls: number | null;
  type: string | null;
  pad: Pad;
  planetary: boolean | null;
  price: number | null;
  market_updated_at: string | null;
  outfitting_updated_at: string | null;
  shipyard_updated_at: string | null;
}

  near: string;
  total: number;
  total_capped: boolean;
  stations: StationHit[];
}

export interface SystemInfo {
  name: string;
  id64: string;
  coords: { x: number; y: number; z: number };

  government: string | null;
  security: string | null;
  population: number | null;
  needs_permit: boolean | null;

    name: string;

export interface RouteQuery {
  from: string;
  to: string;
  rangeLy: number;
  efficiency?: number;
  supercharge?: "neutron" | "overcharge";
}

export interface RouteResult {
  from: string;
  to: string;
  distance_ly: number;
  total_jumps: number;
  waypoints: Array<{
    system: string;
    jumps: number;
    distance_jumped_ly: number;
    distance_left_ly: number;
    neutron: boolean;
  }>;
}

interface RawStation {
  name: string;
  system_name?: string;
  distance?: number;
  distance_to_arrival?: number | null;
  type?: string | null;
  is_planetary?: boolean | null;
  large_pads?: number;
  medium_pads?: number;
  small_pads?: number;
  has_large_pad?: boolean;
  has_market?: boolean;
  has_outfitting?: boolean;
  has_shipyard?: boolean;
  services?: Array<{ name: string }>;
  modules?: Array<{ name: string; class?: number; rating?: string; price?: number }>;
  ships?: Array<{ name: string; price?: number }>;
  market_updated_at?: string | null;
  outfitting_updated_at?: string | null;
  shipyard_updated_at?: string | null;
}

const SERVICE_FILTERS: Record<StationService, Record<string, unknown>> = {
  material_trader_raw: { material_trader: { value: ["Raw"] } },
  material_trader_manufactured: { material_trader: { value: ["Manufactured"] } },
  material_trader_encoded: { material_trader: { value: ["Encoded"] } },
  tech_broker_human: { technology_broker: { value: ["Human"] } },
  tech_broker_guardian: { technology_broker: { value: ["Guardian"] } },
  interstellar_factors: { services: [{ name: { value: ["Interstellar Factors Contact"] } }] },
};

const COUNT_CAP = 10_000;

// Spansh spells ship names inconsistently ("Python MkII", "Kestrel Mk II").
const shipKey = (s: string) => s.toLowerCase().replace(/[\s-]/g, "");

function pad(s: RawStation): Pad {
  if (s.has_large_pad || (s.large_pads ?? 0) > 0) return "L";
  if ((s.medium_pads ?? 0) > 0) return "M";
  if ((s.small_pads ?? 0) > 0) return "S";
  return null;
}

export class SpanshClient {
  private readonly baseUrl: string;
  private readonly minIntervalMs: number;
  private readonly sleep: (ms: number) => Promise<void>;
  private readonly routeTimeoutMs: number;
  private gate: Promise<void> = Promise.resolve();
  private lastStart = 0;

  constructor(
    private readonly http: HttpClient,
    private readonly cache: TtlCache<unknown>,
    opts: {
      baseUrl?: string;
      minIntervalMs?: number;
      sleep?: (ms: number) => Promise<void>;
      routeTimeoutMs?: number;
    } = {},
  ) {
    this.baseUrl = opts.baseUrl ?? "https://spansh.co.uk/api";
    this.minIntervalMs = opts.minIntervalMs ?? 1000;
    this.sleep = opts.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms)));
    this.routeTimeoutMs = opts.routeTimeoutMs ?? 120_000;
  }

  async resolveShip(name: string): Promise<string> {
    const body = (await this.cached("ships", () =>
      this.get("/stations/field_values/ships"),
    )) as { values: { name: string[] } };
    const names = body.values.name;
    const exact = names.find((n) => shipKey(n) === shipKey(name));
    if (exact) return exact;
    const near = [...names]
      .sort((a, b) => distance(shipKey(a), shipKey(name)) - distance(shipKey(b), shipKey(name)))
      .slice(0, 5);
    throw new UserError(`Unknown ship "${name}". Closest: ${near.join(", ")}`);
  }

  async findStations(q: StationQuery): Promise<StationResult> {
    const given = [q.module, q.ship, q.service].filter((x) => x !== undefined).length;
    if (given !== 1) throw new UserError("Give exactly one of module, ship or service");

    const filters: Record<string, unknown> = {};
    let shipName: string | undefined;
    if (q.module) {
      const m: Record<string, unknown> = { name: { value: [q.module.name] } };
      if (q.module.class !== undefined) m.class = { value: [String(q.module.class)] };
      if (q.module.rating !== undefined) m.rating = { value: [q.module.rating.toUpperCase()] };
      filters.modules = [m];
    } else if (q.ship) {
      shipName = await this.resolveShip(q.ship);
      filters.ships = [{ name: { value: [shipName] } }];
    } else if (q.service) {
      Object.assign(filters, SERVICE_FILTERS[q.service]);
    }
    if (q.largePad) filters.has_large_pad = { value: true };
    if (q.maxDistanceLy !== undefined) filters.distance = { min: 0, max: q.maxDistanceLy };

    const body = {
      filters,
      sort: [{ distance: { direction: "asc" } }],
      size: q.limit,
      page: 0,
      reference_system: q.near,
    };
    const raw = (await this.cached(`stations:${JSON.stringify(body)}`, async () => {
      try {
        return await this.post("/stations/search", JSON.stringify(body), "application/json");
      } catch (err) {
        if (err instanceof SpanshError && err.status === 400) {
          throw new UserError(
            `Spansh rejected the search. Check that "${q.near}" is an exact system name (look it up with spansh_system).`,
          );
        }
        throw err;
      }
    })) as { count: number; results?: RawStation[] };

    const stations = (raw.results ?? []).map((s) => this.hit(s, q, shipName));
    return {
      near: q.near,
      total: raw.count,
      total_capped: raw.count >= COUNT_CAP,
      stations,
    };
  }

  async system(name: string, stationLimit: number): Promise<SystemInfo> {
    const found = (await this.cached(`search:${name.toLowerCase()}`, () =>
      this.get(`/search/systems?${new URLSearchParams({ q: name })}`),
    )) as { results?: Array<{ id64: number | string; name: string }> };
    const results = found.results ?? [];
    const match = results.find((r) => r.name.toLowerCase() === name.toLowerCase());
    if (!match) {
      const hint = results.length
        ? ` Closest: ${results.slice(0, 5).map((r) => r.name).join(", ")}`
        : "";
      throw new UserError(`System "${name}" not found on Spansh.${hint}`);
    }
    const detail = (await this.cached(`system:${match.id64}`, () =>
      this.get(`/system/${match.id64}`),
    )) as { record: Record<string, unknown> & { stations?: RawStation[] } };
    const r = detail.record;
    const stations = [...(r.stations ?? [])].sort(
      (a, b) => (a.distance_to_arrival ?? Infinity) - (b.distance_to_arrival ?? Infinity),
    );
    return {
      name: String(r.name),
      id64: String(r.id64),
      coords: { x: Number(r.x), y: Number(r.y), z: Number(r.z) },
      allegiance: (r.allegiance as string | undefined) ?? null,
      government: (r.government as string | undefined) ?? null,
      security: (r.security as string | undefined) ?? null,
      population: (r.population as number | undefined) ?? null,
      needs_permit: (r.needs_permit as boolean | undefined) ?? null,
      station_count: stations.length,
      stations: stations.slice(0, stationLimit).map((s) => ({
        name: s.name,
        type: s.type ?? null,
        arrival_ls: s.distance_to_arrival ?? null,
        pad: pad(s),
        market: s.has_market ?? false,
        outfitting: s.has_outfitting ?? false,
        shipyard: s.has_shipyard ?? false,
        services: (s.services ?? []).map((x) => x.name),
      })),
    };
  }

  async route(q: RouteQuery): Promise<RouteResult> {
    const form = new URLSearchParams({
      from: q.from,
      to: q.to,
      range: String(q.rangeLy),
      efficiency: String(q.efficiency ?? 60),
      supercharge_multiplier: q.supercharge === "overcharge" ? "6" : "4",
    });
    return (await this.cached(`route:${form}`, async () => {
      const submitted = (await this.post(
        "/route",
        form.toString(),
        "application/x-www-form-urlencoded",
      )) as { job: string };
      let waited = 0;
      let delay = 1000;
      for (;;) {
        if (waited >= this.routeTimeoutMs) throw new UserError("Spansh route timed out");
        await this.sleep(delay);
        waited += delay;
        delay = Math.min(delay * 2, 16_000);
        const { status, body } = await this.raw(`/results/${submitted.job}`);
        if (status === 202) continue;
        const b = body as { status?: string; error?: string; result?: RawRoute };
        if (status === 200 && b.status === "ok" && b.result) return mapRoute(b.result);
        throw new UserError(`Spansh: ${b.error ?? `route failed (HTTP ${status})`}`);
      }
    })) as RouteResult;
  }

  private hit(s: RawStation, q: StationQuery, shipName?: string): StationHit {
    let price: number | null = null;
    if (q.module) {
      const m = (s.modules ?? []).find(
        (x) =>
          x.name === q.module!.name &&
          (q.module!.class === undefined || x.class === q.module!.class) &&
          (q.module!.rating === undefined || x.rating === q.module!.rating.toUpperCase()),
      );
      price = m?.price ?? null;
    } else if (shipName) {
      price = (s.ships ?? []).find((x) => x.name === shipName)?.price ?? null;
    }
    return {
      name: s.name,
      system: s.system_name ?? "",
      distance_ly: s.distance ?? 0,
      arrival_ls: s.distance_to_arrival ?? null,
      type: s.type ?? null,
      pad: pad(s),
      planetary: s.is_planetary ?? null,
      price,
      market_updated_at: s.market_updated_at ?? null,
      outfitting_updated_at: s.outfitting_updated_at ?? null,
      shipyard_updated_at: s.shipyard_updated_at ?? null,
    };
  }

  private cached(key: string, load: () => Promise<unknown>): Promise<unknown> {
    return this.cache.getOrLoad(key, load);
  }

  private async get(path: string): Promise<unknown> {
    const { status, body } = await this.raw(path);
    if (status >= 400) throw new SpanshError(status, body);
    return body;
  }

  private async post(path: string, body: string, contentType: string): Promise<unknown> {
    const res = await this.raw(path, { method: "POST", body, headers: { "content-type": contentType } });
    if (res.status >= 400) throw new SpanshError(res.status, res.body);
    return res.body;
  }

  // Spansh publishes no quota; spacing requests keeps us a polite client.
  private async raw(path: string, init: RequestInit = {}): Promise<{ status: number; body: unknown }> {
    const turn = this.gate.then(async () => {
      const wait = this.lastStart + this.minIntervalMs - Date.now();
      if (wait > 0) await this.sleep(wait);
      this.lastStart = Date.now();
    });
    this.gate = turn.catch(() => undefined);
    await turn;
    const res = await this.http.request(`${this.baseUrl}${path}`, init);
    const text = await res.text();
    let body: unknown;
    try {
      body = text ? parseSpanshJson(text) : undefined;
    } catch {
      throw new UserError(`Spansh returned invalid JSON (HTTP ${res.status})`);
    }
    return { status: res.status, body };
  }
}

class SpanshError extends UserError {
  constructor(
    readonly status: number,
    body: unknown,
  ) {
    const msg = (body as { error?: string } | undefined)?.error;
    super(`Spansh: ${msg ?? `HTTP ${status}`}`);
  }
}

interface RawRoute {
  source_system: string;
  destination_system: string;
  distance: number;
  total_jumps: number;
  system_jumps: Array<{
    system: string;
    jumps: number;
    distance_jumped: number;
    distance_left: number;
    neutron_star: boolean;
  }>;
}

function mapRoute(r: RawRoute): RouteResult {
  return {
    from: r.source_system,
    to: r.destination_system,
    distance_ly: r.distance,
    total_jumps: r.total_jumps,
    waypoints: r.system_jumps.map((j) => ({
      system: j.system,
      jumps: j.jumps,
      distance_jumped_ly: j.distance_jumped,
      distance_left_ly: j.distance_left,
      neutron: j.neutron_star,
    })),
  };
}
```

  - `normKey(s: string): string` — lowercase, keep `[a-z0-9]`, then apply `ALIASES` (normalized typo/variant → normalized canonical).

Throws `CatalogError("Catalog data is invalid: <reason>")` on parse failure or counts below minimum. Warnings: material names in blueprints/experimentals that do not resolve (except `Merc Coin`), and engineer names in `modules.json` that do not resolve.
  - `class Catalog` with:
    - `counts(): { blueprints: number; experimentals: number; materials: number; modules: number; engineers: number }`
    - `blueprint(name: string, module?: string): BlueprintInfo` where `BlueprintInfo = { id: string; name: string; modules: string[]; grades: Record<string, Array<MaterialCount & { grade: number | null; kind: string | null; trade_group: string | null }>>; experimentals: Experimental[] }`. Matches `id` or display `name` via `normKey`; when several match, filters by `module` against `modules` and group names; still ambiguous → `UserError` listing `id (modules)` options; none → `UserError("Unknown blueprint \"<name>\". Closest: ...")` with 5 nearest by Levenshtein over ids and names.
    - `engineersFor(blueprintId: string, module?: string): EngineerOffer[]` where `EngineerOffer = { engineer: string; max_grade: number; system: string | null; base: string | null; invite: string | null; unlock: string | null; reputation: string | null; odyssey: boolean | null }`, sorted by `max_grade` desc then name. Groups are those containing the blueprint, filtered by `module` when given.
    - `engineer(name: string): Engineer & { offers: Array<{ group: string; module: string; blueprint: string; max_grade: number }> }`
    - `material(name: string): Material & { same_group: Material[]; trade_rules: string }`
    - `module(query: string): Array<OutfittingItem & { group: string | null }>` — exact symbol match (case-insensitive) or display-name match; max 20.

```js
// Regenerates src/catalog/data/{engineers,groups}.json from upstream.
// Run when Frontier adds engineers or module types: npm run catalog:statics
import { writeFile } from "node:fs/promises";

const UA = { "user-agent": "ed-mcp-catalog-statics (+https://github.com/pilotso11/ed-mcp)" };
const get = async (url) => {
  const res = await fetch(url, { headers: UA });
  if (!res.ok) throw new Error(`${url}: HTTP ${res.status}`);
  return res.text();
};

const ENGINEERS_CS =
  "https://raw.githubusercontent.com/EDDiscovery/EliteDangerousCore/master/EliteDangerous/FrontierData/Items/Engineers.cs";
const OUTFITTING = "https://raw.githubusercontent.com/EDCD/FDevIDs/master/outfitting.csv";
const CORIOLIS_TREE = "https://api.github.com/repos/EDCD/coriolis-data/git/trees/develop?recursive=1";
const CORIOLIS_RAW = "https://raw.githubusercontent.com/EDCD/coriolis-data/develop/";

const str = String.raw`"((?:[^"\\]|\\.)*)"`;
const num = String.raw`(-?[\d.]+)`;
const bool = String.raw`(true|false)`;
const ENTRY = new RegExp(
  String.raw`new EngineeringInfo\(\s*` +
    [str, str, str, num, num, num, str, str, str, str, str, bool, bool].join(String.raw`\s*,\s*`) +
    String.raw`\s*\)`,
  "g",
);

function parseEngineers(cs) {
  const out = [];
  for (const m of cs.matchAll(ENTRY)) {
    const s = (i) => m[i].replace(/\\"/g, '"');
    out.push({
      name: s(1), system: s(2), base: s(3),
      coords: { x: Number(m[4]), y: Number(m[5]), z: Number(m[6]) },
      planet: s(7), discovery: s(8), invite: s(9), unlock: s(10), reputation: s(11),
      permit: m[12] === "true", odyssey: m[13] === "true",
    });
  }
  if (out.length < 38) throw new Error(`expected at least 38 engineers, parsed ${out.length}`);
  return out.sort((a, b) => a.name.localeCompare(b.name));
}

function parseCsv(text) {
  const [head, ...rows] = text.trim().split(/\r?\n/);
  const cols = head.split(",");
  return rows.map((r) => {
    const cells = r.split(",");
    return Object.fromEntries(cols.map((c, i) => [c, (cells[i] ?? "").trim()]));
  });
}

async function buildGroups() {
  const names = new Map(parseCsv(await get(OUTFITTING)).map((r) => [r.symbol.toLowerCase(), r.name]));
  const tree = JSON.parse(await get(CORIOLIS_TREE));
  const files = tree.tree.filter((t) => /^modules\/.+\.json$/.test(t.path)).map((t) => t.path);
  const groups = {};
  for (const path of files) {
    const data = JSON.parse(await get(CORIOLIS_RAW + path));
    for (const [grp, items] of Object.entries(data)) {
      if (!Array.isArray(items)) continue;
      for (const item of items) {
        const name = names.get(String(item.symbol ?? "").toLowerCase()) ?? item.name;
        if (!name) continue;
        (groups[grp] ??= new Set()).add(name);
      }
    }
  }
  return Object.fromEntries(
    Object.entries(groups)
      .sort(([a], [b]) => a.localeCompare(b))
      .map(([g, set]) => [g, [...set].sort()]),
  );
}

const engineers = parseEngineers(await get(ENGINEERS_CS));
const groups = await buildGroups();
await writeFile("src/catalog/data/engineers.json", JSON.stringify(engineers, null, 2) + "\n");
await writeFile("src/catalog/data/groups.json", JSON.stringify(groups, null, 2) + "\n");
console.log(`engineers: ${engineers.length}, groups: ${Object.keys(groups).length}`);
```

```ts
export function parseCsv(text: string): Array<Record<string, string>> {
  const rows: string[][] = [];
  let row: string[] = [];
  let cell = "";
  let quoted = false;
  for (let i = 0; i < text.length; i++) {
    const c = text[i]!;
    if (quoted) {
      if (c === '"' && text[i + 1] === '"') {
        cell += '"';
        i++;
      } else if (c === '"') quoted = false;
      else cell += c;
    } else if (c === '"') quoted = true;
    else if (c === ",") {
      row.push(cell);
      cell = "";
    } else if (c === "\n" || c === "\r") {
      if (c === "\r" && text[i + 1] === "\n") i++;
      row.push(cell);
      rows.push(row);
      row = [];
      cell = "";
    } else cell += c;
  }
  if (cell !== "" || row.length) {
    row.push(cell);
    rows.push(row);
  }
  const [head, ...body] = rows.filter((r) => r.some((c) => c.trim() !== ""));
  if (!head) return [];
  const cols = head.map((h) => h.trim());
  return body.map((r) => Object.fromEntries(cols.map((c, i) => [c, (r[i] ?? "").trim()])));
}
```

`src/catalog/build.ts`:
```ts
import { UserError } from "../errors.js";
import { Catalog } from "./catalog.js";
import { parseCsv } from "./csv.js";
import { normKey } from "./names.js";
import type {
  Blueprint,
  Experimental,
  Material,
  MaterialCount,
  ModuleGroup,
  OutfittingItem,
  RawSources,
  Statics,
} from "./types.js";

export class CatalogError extends UserError {
  override name = "CatalogError";
}

// Paid in Merc Coin, a currency no materials file lists.
const NON_MATERIALS = new Set([normKey("Merc Coin")]);

function json(raw: string, label: string): Record<string, unknown> {
  try {
    const v = JSON.parse(raw) as unknown;
    if (!v || typeof v !== "object" || Array.isArray(v)) throw new Error("not an object");
    return v as Record<string, unknown>;
  } catch (err) {
    throw new CatalogError(`Catalog data is invalid: ${label}: ${(err as Error).message}`);
  }
}

const counts = (c: unknown): MaterialCount[] =>
  Object.entries((c ?? {}) as Record<string, number>).map(([name, count]) => ({ name, count }));

export function buildCatalog(
  raw: RawSources,
  statics: Statics,
  opts: { minBlueprints?: number; minMaterials?: number; minOutfitting?: number } = {},
): { catalog: Catalog; warnings: string[] } {
  const bpJson = json(raw.blueprints, "blueprints");
  const spJson = json(raw.specials, "specials");
  const modJson = json(raw.modifications, "modifications");

  const blueprints: Blueprint[] = Object.entries(bpJson).map(([id, v]) => {
    const b = v as { fdname?: string; name?: string; modulename?: string[]; grades?: Record<string, { components?: unknown }> };
    return {
      id: b.fdname ?? id,
      name: b.name ?? id,
      modules: b.modulename ?? [],
      grades: Object.fromEntries(
        Object.entries(b.grades ?? {}).map(([g, x]) => [g, counts(x.components)]),
      ),
    };
  });

  const experimentals: Experimental[] = Object.entries(spJson).map(([id, v]) => {
    const s = v as { edname?: string; name?: string; description?: string; components?: unknown };
    return {
      id: s.edname ?? id,
      name: s.name ?? id,
      description: s.description ?? "",
      materials: counts(s.components),
    };
  });

  const groups: ModuleGroup[] = Object.entries(modJson).map(([id, v]) => {
    const g = v as {
      blueprints?: Record<string, { grades?: Record<string, { engineers?: string[] }> }>;
      specials?: string[];
    };
    return {
      id,
      names: statics.groups[id] ?? [],
      blueprints: Object.fromEntries(
        Object.entries(g.blueprints ?? {}).map(([bp, x]) => [
          bp,
          Object.fromEntries(
            Object.entries(x.grades ?? {}).map(([grade, y]) => [grade, y.engineers ?? []]),
          ),
        ]),
      ),
      experimentals: g.specials ?? [],
    };
  });

  const materials: Material[] = parseCsv(raw.materials)
    .filter((r) => r.symbol && r.name && ["Raw", "Manufactured", "Encoded"].includes(r.type ?? ""))
    .map((r) => ({
      symbol: r.symbol!,
      name: r.name!,
      kind: r.type as Material["kind"],
      grade: Number(r.rarity),
      trade_group: !r.category || r.category === "None" ? null : r.category,
    }));

  const outfitting: OutfittingItem[] = parseCsv(raw.outfitting)
    .filter((r) => r.symbol && r.name)
    .map((r) => ({
      symbol: r.symbol!,
      name: r.name!,
      category: r.category ?? "",
      class: r.class ? Number(r.class) : null,
      rating: r.rating || null,
      mount: r.mount || null,
      ship: r.ship || null,
    }));

  const min = { blueprints: 60, materials: 100, outfitting: 500, ...strip(opts) };
  if (blueprints.length < min.blueprints) {
    throw new CatalogError(`Catalog data is invalid: only ${blueprints.length} blueprints`);
  }
  if (materials.length < min.materials) {
    throw new CatalogError(`Catalog data is invalid: only ${materials.length} materials`);
  }
  if (outfitting.length < min.outfitting) {
    throw new CatalogError(`Catalog data is invalid: only ${outfitting.length} outfitting items`);
  }

  const catalog = new Catalog({ blueprints, experimentals, groups, materials, outfitting, engineers: statics.engineers });

  const warnings: string[] = [];
  const known = new Set(materials.map((m) => normKey(m.name)));
  const unknownMats = new Set<string>();
  for (const list of [...blueprints.flatMap((b) => Object.values(b.grades)), ...experimentals.map((e) => e.materials)]) {
    for (const { name } of list) {
      const k = normKey(name);
      if (!known.has(k) && !NON_MATERIALS.has(k)) unknownMats.add(name);
    }
  }
  for (const n of [...unknownMats].sort()) warnings.push(`Unknown material: ${n}`);
  const engineerKeys = new Set(statics.engineers.map((e) => normKey(e.name)));
  const unknownEng = new Set<string>();
  for (const g of groups) {
    for (const grades of Object.values(g.blueprints)) {
      for (const names of Object.values(grades)) {
        for (const n of names) if (!engineerKeys.has(normKey(n))) unknownEng.add(n);
      }
    }
  }
  for (const n of [...unknownEng].sort()) warnings.push(`Unknown engineer in modules.json: ${n}`);
  return { catalog, warnings };
}

function strip(o: { minBlueprints?: number; minMaterials?: number; minOutfitting?: number }) {
  const out: Partial<{ blueprints: number; materials: number; outfitting: number }> = {};
  if (o.minBlueprints !== undefined) out.blueprints = o.minBlueprints;
  if (o.minMaterials !== undefined) out.materials = o.minMaterials;
  if (o.minOutfitting !== undefined) out.outfitting = o.minOutfitting;
  return out;
}
```

```ts
import { distance } from "fastest-levenshtein";
import { UserError } from "../errors.js";
import { normKey } from "./names.js";
import type {
  Blueprint,
  Engineer,
  Experimental,
  Material,
  MaterialCount,
  ModuleGroup,
  OutfittingItem,
} from "./types.js";

export interface BlueprintInfo {
  id: string;
  name: string;
  modules: string[];
  grades: Record<
    string,
    Array<MaterialCount & { grade: number | null; kind: string | null; trade_group: string | null }>
  >;
  experimentals: Experimental[];
}

export interface EngineerOffer {
  engineer: string;
  max_grade: number;
  system: string | null;
  base: string | null;
  invite: string | null;
  unlock: string | null;
  reputation: string | null;
  odyssey: boolean | null;
}

const TRADE_RULES =
  "Trade at a material trader of the same kind (raw, manufactured or encoded). " +
  "Within a trade group: 6 of one grade buy 1 of the next grade up; 1 of a grade buys 3 of the grade below. " +
  "Across trade groups of the same kind, trades cost 6 times more at the same grade. " +
  "Guardian and Thargoid materials (no trade group) cannot be traded.";

function nearest(query: string, options: string[], n = 5): string[] {
  const q = normKey(query);
  return [...new Set(options)]
    .map((o) => ({ o, d: distance(q, normKey(o)) }))
    .sort((a, b) => a.d - b.d)
    .slice(0, n)
    .map((x) => x.o);
}

export class Catalog {
  private readonly materialByKey = new Map<string, Material>();
  private readonly engineerByKey = new Map<string, Engineer>();

  constructor(
    private readonly d: {
      blueprints: Blueprint[];
      experimentals: Experimental[];
      groups: ModuleGroup[];
      materials: Material[];
      outfitting: OutfittingItem[];
      engineers: Engineer[];
    },
  ) {
    for (const m of d.materials) {
      this.materialByKey.set(normKey(m.name), m);
      this.materialByKey.set(normKey(m.symbol), m);
    }
    for (const e of d.engineers) this.engineerByKey.set(normKey(e.name), e);
  }

  counts() {
    return {
      blueprints: this.d.blueprints.length,
      experimentals: this.d.experimentals.length,
      materials: this.d.materials.length,
      modules: this.d.outfitting.length,
      engineers: this.d.engineers.length,
    };
  }

  blueprint(name: string, module?: string): BlueprintInfo {
    const k = normKey(name);
    let hits = this.d.blueprints.filter((b) => normKey(b.id) === k || normKey(b.name) === k);
    if (hits.length > 1 && module) {
      const mk = normKey(module);
      hits = hits.filter(
        (b) =>
          b.modules.some((m) => normKey(m) === mk) ||
          this.groupsFor(b.id).some((g) => g.names.some((n) => normKey(n) === mk)),
      );
    }
    if (hits.length === 0) {
      const options = this.d.blueprints.flatMap((b) => [b.id, b.name]);
      throw new UserError(`Unknown blueprint "${name}". Closest: ${nearest(name, options).join(", ")}`);
    }
    if (hits.length > 1) {
      const list = hits.map((b) => `${b.id} (${b.modules.join("/")})`).join(", ");
      throw new UserError(`Blueprint "${name}" is ambiguous; give module or use an id: ${list}`);
    }
    const b = hits[0]!;
    const groups = this.groupsFor(b.id, module);
    const expIds = new Set(groups.flatMap((g) => g.experimentals));
    return {
      id: b.id,
      name: b.name,
      modules: b.modules,
      grades: Object.fromEntries(
        Object.entries(b.grades).map(([g, list]) => [g, list.map((m) => this.enrich(m))]),
      ),
      experimentals: this.d.experimentals.filter((e) => expIds.has(e.id)),
    };
  }

  engineersFor(blueprintId: string, module?: string): EngineerOffer[] {
    const best = new Map<string, { name: string; grade: number }>();
    for (const g of this.groupsFor(blueprintId, module)) {
      for (const [grade, names] of Object.entries(g.blueprints[blueprintId] ?? {})) {
        for (const raw of names) {
          const key = normKey(raw);
          const name = this.engineerByKey.get(key)?.name ?? raw;
          const prev = best.get(key);
          if (!prev || Number(grade) > prev.grade) best.set(key, { name, grade: Number(grade) });
        }
      }
    }
    return [...best.entries()]
      .map(([key, { name, grade }]) => {
        const e = this.engineerByKey.get(key);
        return {
          engineer: name,
          max_grade: grade,
          system: e?.system ?? null,
          base: e?.base ?? null,
          invite: e?.invite ?? null,
          unlock: e?.unlock ?? null,
          reputation: e?.reputation ?? null,
          odyssey: e?.odyssey ?? null,
        };
      })
      .sort((a, b) => b.max_grade - a.max_grade || a.engineer.localeCompare(b.engineer));
  }

  engineer(name: string): Engineer & {
    offers: Array<{ group: string; module: string; blueprint: string; max_grade: number }>;
  } {
    const e = this.engineerByKey.get(normKey(name));
    if (!e) {
      throw new UserError(
        `Unknown engineer "${name}". Closest: ${nearest(name, this.d.engineers.map((x) => x.name)).join(", ")}`,
      );
    }
    const key = normKey(e.name);
    const offers: Array<{ group: string; module: string; blueprint: string; max_grade: number }> = [];
    for (const g of this.d.groups) {
      for (const [bp, grades] of Object.entries(g.blueprints)) {
        let max = 0;
        for (const [grade, names] of Object.entries(grades)) {
          if (names.some((n) => normKey(n) === key)) max = Math.max(max, Number(grade));
        }
        if (max > 0) offers.push({ group: g.id, module: g.names[0] ?? g.id, blueprint: bp, max_grade: max });
      }
    }
    return { ...e, offers };
  }

  material(name: string): Material & { same_group: Material[]; trade_rules: string } {
    const m = this.materialByKey.get(normKey(name));
    if (!m) {
      throw new UserError(
        `Unknown material "${name}". Closest: ${nearest(name, this.d.materials.map((x) => x.name)).join(", ")}`,
      );
    }
    const same = m.trade_group
      ? this.d.materials
          .filter((x) => x.kind === m.kind && x.trade_group === m.trade_group)
          .sort((a, b) => a.grade - b.grade)
      : [m];
    return { ...m, same_group: same, trade_rules: TRADE_RULES };
  }

  module(query: string): Array<OutfittingItem & { group: string | null }> {
    const q = query.toLowerCase();
    const bySymbol = this.d.outfitting.filter((o) => o.symbol.toLowerCase() === q);
    const hits = bySymbol.length
      ? bySymbol
      : this.d.outfitting.filter((o) => normKey(o.name) === normKey(query));
    if (!hits.length) {
      throw new UserError(
        `Unknown module "${query}". Closest: ${nearest(query, this.d.outfitting.map((o) => o.name)).join(", ")}`,
      );
    }
    return hits.slice(0, 20).map((o) => ({
      ...o,
      group: this.d.groups.find((g) => g.names.includes(o.name))?.id ?? null,
    }));
  }

  private groupsFor(blueprintId: string, module?: string): ModuleGroup[] {
    const groups = this.d.groups.filter((g) => blueprintId in g.blueprints);
    if (!module) return groups;
    const mk = normKey(module);
    const filtered = groups.filter((g) => g.names.some((n) => normKey(n) === mk) || normKey(g.id) === mk);
    return filtered.length ? filtered : groups;
  }

  private enrich(m: MaterialCount) {
    const hit = this.materialByKey.get(normKey(m.name));
    return {
      name: hit?.name ?? m.name,
      count: m.count,
      grade: hit?.grade ?? null,
      kind: hit?.kind ?? null,
      trade_group: hit?.trade_group ?? null,
    };
  }
}
```

```ts
import { mkdir, readFile, rename, writeFile } from "node:fs/promises";
import path from "node:path";
import { UserError } from "../errors.js";
import type { HttpClient } from "../http/client.js";
import type { Refreshable } from "../tools/cache.js";
import { buildCatalog } from "./build.js";
import type { Catalog } from "./catalog.js";
import engineers from "./data/engineers.json" with { type: "json" };
import groups from "./data/groups.json" with { type: "json" };
import type { Engineer, RawSources, Statics } from "./types.js";

export const CATALOG_SOURCES: Record<keyof RawSources, string> = {
  blueprints: "https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/blueprints.json",
  specials: "https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/specials.json",
  modifications: "https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/modules.json",
  materials: "https://raw.githubusercontent.com/EDCD/FDevIDs/master/material.csv",
  outfitting: "https://raw.githubusercontent.com/EDCD/FDevIDs/master/outfitting.csv",
};

const KEYS = Object.keys(CATALOG_SOURCES) as Array<keyof RawSources>;
const DEFAULT_STATICS: Statics = {
  engineers: engineers as Engineer[],
  groups: groups as Record<string, string[]>,
};

interface Meta {
  version: 1;
  checked_at: string;
  files: Record<string, { etag: string | null; fetched_at: string }>;
}

export interface CatalogStatus {
  state: "empty" | "ready" | "error";
  checked_at: string | null;
  files: Meta["files"];
  counts: ReturnType<Catalog["counts"]> | null;
  warnings: string[];
  last_error: string | null;
}

export class CatalogService implements Refreshable {
  readonly name = "catalog";
  private catalog: Catalog | null = null;
  private texts: Partial<RawSources> = {};
  private meta: Meta | null = null;
  private warnings: string[] = [];
  private lastError: string | null = null;
  private loading: Promise<Catalog> | null = null;
  private refreshing: Promise<{ changed: string[]; unchanged: string[]; warnings: number }> | null =
    null;
  private readonly dir: string;
  private readonly statics: Statics;
  private readonly now: () => number;
  private readonly maxAgeMs: number;
  private readonly minimums: { minBlueprints?: number; minMaterials?: number; minOutfitting?: number };
  private readonly sources: Record<keyof RawSources, string>;

  constructor(
    private readonly http: HttpClient,
    cacheDir: string,
    opts: {
      statics?: Statics;
      now?: () => number;
      maxAgeMs?: number;
      minimums?: { minBlueprints?: number; minMaterials?: number; minOutfitting?: number };
      sources?: Record<keyof RawSources, string>;
    } = {},
  ) {
    this.dir = path.join(cacheDir, "catalog");
    this.statics = opts.statics ?? DEFAULT_STATICS;
    this.now = opts.now ?? Date.now;
    this.maxAgeMs = opts.maxAgeMs ?? 7 * 86_400_000;
    this.minimums = opts.minimums ?? {};
    this.sources = opts.sources ?? CATALOG_SOURCES;
  }

  async get(): Promise<Catalog> {
    if (this.catalog) {
      this.maybeBackgroundRefresh();
      return this.catalog;
    }
    this.loading ??= this.load().finally(() => (this.loading = null));
    return this.loading;
  }

  refresh(): Promise<{ changed: string[]; unchanged: string[]; warnings: number }> {
    this.refreshing ??= this.doRefresh().finally(() => (this.refreshing = null));
    return this.refreshing;
  }

  status(): CatalogStatus {
    return {
      state: this.catalog ? "ready" : this.lastError ? "error" : "empty",
      checked_at: this.meta?.checked_at ?? null,
      files: this.meta?.files ?? {},
      counts: this.catalog?.counts() ?? null,
      warnings: this.warnings,
      last_error: this.lastError,
    };
  }

  private async load(): Promise<Catalog> {
    if (await this.loadDisk()) return this.catalog!;
    try {
      await this.refresh();
    } catch (err) {
      throw new UserError(
        `Game data catalog is not available: ${(err as Error).message}. It downloads from GitHub on first use; ` +
          'check the network, then call cache_refresh with source "catalog".',
      );
    }
    return this.catalog!;
  }

  private async loadDisk(): Promise<boolean> {
    try {
      const meta = JSON.parse(await readFile(path.join(this.dir, "meta.json"), "utf8")) as Meta;
      const texts = {} as RawSources;
      for (const k of KEYS) texts[k] = await readFile(path.join(this.dir, `${k}.raw`), "utf8");
      const built = buildCatalog(texts, this.statics, this.minimums);
      this.catalog = built.catalog;
      this.warnings = built.warnings;
      this.texts = texts;
      this.meta = meta;
      return true;
    } catch {
      // Missing or corrupt cache: fall back to a full download.
      this.texts = {};
      this.meta = null;
      return false;
    }
  }

  private maybeBackgroundRefresh(): void {
    const checked = this.meta ? Date.parse(this.meta.checked_at) : 0;
    if (this.refreshing || this.now() - checked <= this.maxAgeMs) return;
    this.refresh().catch(() => undefined); // recorded in lastError by doRefresh
  }

  private async doRefresh(): Promise<{ changed: string[]; unchanged: string[]; warnings: number }> {
    try {
      const next = { ...this.texts } as RawSources;
      const files = { ...(this.meta?.files ?? {}) };
      const changed: string[] = [];
      const unchanged: string[] = [];
      const stamp = new Date(this.now()).toISOString();
      for (const k of KEYS) {
        const etag = files[k]?.etag;
        const headers: Record<string, string> = {};
        if (etag && this.texts[k] !== undefined) headers["if-none-match"] = etag;
        let res: Response;
        try {
          res = await this.http.request(this.sources[k], { headers });
        } catch (err) {
          throw new UserError(`${k}: ${(err as Error).message}`);
        }
        if (res.status === 304) {
          unchanged.push(k);
          continue;
        }
        if (res.status !== 200) throw new UserError(`${k}: HTTP ${res.status}`);
        next[k] = await res.text();
        files[k] = { etag: res.headers.get("etag"), fetched_at: stamp };
        changed.push(k);
      }
      const built = buildCatalog(next, this.statics, this.minimums);
      await mkdir(this.dir, { recursive: true });
      for (const k of changed) await atomicWrite(path.join(this.dir, `${k}.raw`), next[k as keyof RawSources]);
      const meta: Meta = { version: 1, checked_at: stamp, files };
      await atomicWrite(path.join(this.dir, "meta.json"), JSON.stringify(meta, null, 2));
      this.catalog = built.catalog;
      this.warnings = built.warnings;
      this.texts = next;
      this.meta = meta;
      this.lastError = null;
      return { changed, unchanged, warnings: built.warnings.length };
    } catch (err) {
      this.lastError = (err as Error).message;
      throw new UserError(`Catalog refresh failed, keeping current data: ${this.lastError}`);
    }
  }
}

async function atomicWrite(file: string, text: string): Promise<void> {
  const tmp = `${file}.${process.pid}.tmp`;
  await writeFile(tmp, text);
  await rename(tmp, file);
}
```

`src/slef/parse.ts`:
```ts
import { UserError } from "../errors.js";

export type SlotKind = "core" | "hardpoint" | "utility" | "internal" | "military" | "other";

export interface SlefEngineering {
  blueprint: string;
  grade: number;
  quality: number | null;
  experimental: string | null;
}

export interface SlefModule {
  slot: string;
  kind: SlotKind;
  slot_size: number | null;
  item: string;
  on: boolean | null;
  priority: number | null;
  value: number | null;
  engineering: SlefEngineering | null;
}

export interface SlefBuild {
  source: { app: string | null; version: string | null; url: string | null };
  ship: string;
  name: string | null;
  ident: string | null;
  modules: SlefModule[];
}

const CORE = new Set([
  "armour",
  "powerplant",
  "mainengines",
  "frameshiftdrive",
  "lifesupport",
  "powerdistributor",
  "radar",
  "fueltank",
]);
const HARDPOINT_SIZE: Record<string, number> = { small: 1, medium: 2, large: 3, huge: 4 };
const COSMETIC =
  /^(paintjob|decal\d*|shipname\d*|shipid\d*|shipkit|bobble\d*|weaponcolour|enginecolour|vesselvoice|stringlights|cockpit)/;

interface RawModule {
  Slot?: unknown;
  Item?: unknown;
  On?: unknown;
  Priority?: unknown;
  Value?: unknown;
  Engineering?: {
    BlueprintName?: unknown;
    Level?: unknown;
    Quality?: unknown;
    ExperimentalEffect?: unknown;
  };
}

function classify(slot: string, item: string): { kind: SlotKind; size: number | null } {
  const s = slot.toLowerCase();
  const itemSize = item.match(/_size(\d+)/i);
  if (CORE.has(s)) return { kind: "core", size: itemSize ? Number(itemSize[1]) : null };
  const hp = s.match(/^(small|medium|large|huge)hardpoint\d+$/);
  if (hp) return { kind: "hardpoint", size: HARDPOINT_SIZE[hp[1]!]! };
  if (/^tinyhardpoint\d+$/.test(s)) return { kind: "utility", size: 0 };
  const internal = s.match(/^slot\d+_size(\d+)$/);
  if (internal) return { kind: "internal", size: Number(internal[1]) };
  if (/^military\d+$/.test(s)) return { kind: "military", size: itemSize ? Number(itemSize[1]) : null };
  return { kind: "other", size: null };
}

const num = (v: unknown) => (typeof v === "number" && Number.isFinite(v) ? v : null);
const str = (v: unknown) => (typeof v === "string" && v !== "" ? v : null);

function parseModule(m: RawModule): SlefModule | null {
  const slot = str(m.Slot);
  const item = str(m.Item)?.toLowerCase();
  if (!slot || !item || COSMETIC.test(slot.toLowerCase())) return null;
  const { kind, size } = classify(slot, item);
  const e = m.Engineering;
  const blueprint = str(e?.BlueprintName);
  return {
    slot,
    kind,
    slot_size: size,
    item,
    on: typeof m.On === "boolean" ? m.On : null,
    priority: num(m.Priority),
    value: num(m.Value),
    engineering:
      e && blueprint
        ? {
            blueprint,
            grade: num(e.Level) ?? 0,
            quality: num(e.Quality),
            experimental: str(e.ExperimentalEffect),
          }
        : null,
  };
}

function parseEntry(entry: unknown): SlefBuild {
  const o = entry as { header?: Record<string, unknown>; data?: Record<string, unknown> } & Record<
    string,
    unknown
  >;
  const data = (o?.data ?? o) as { Ship?: unknown; ShipName?: unknown; ShipIdent?: unknown; Modules?: unknown };
  const header = o?.data ? (o.header ?? {}) : {};
  const ship = str(data?.Ship);
  if (!ship || !Array.isArray(data.Modules)) {
    throw new UserError("Not a SLEF build: expected { header, data: { Ship, Modules } }");
  }
  return {
    source: {
      app: str(header.appName),
      version: header.appVersion === undefined ? null : String(header.appVersion),
      url: str(header.appURL),
    },
    ship: ship.toLowerCase(),
    name: str(data.ShipName),
    ident: str(data.ShipIdent),
    modules: (data.Modules as RawModule[]).map(parseModule).filter((m): m is SlefModule => m !== null),
  };
}

export function parseSlef(input: unknown): SlefBuild[] {
  let value = input;
  if (typeof input === "string") {
    try {
      value = JSON.parse(input);
    } catch {
      throw new UserError("SLEF is not valid JSON");
    }
  }
  const entries = Array.isArray(value) ? value : [value];
  if (!entries.length) throw new UserError("Not a SLEF build: empty array");
  return entries.map(parseEntry);
}
```

```ts
import type { Catalog } from "../catalog/catalog.js";
import type { CatalogService } from "../catalog/service.js";
import { parseSlef } from "../slef/parse.js";
import { wrap } from "./result.js";

export function registerBuildTools(server: McpServer, deps: { catalog?: CatalogService }): void {
  server.registerTool(
    "build_parse_slef",
    {
      description:
        "Parse a SLEF ship build (export from EDSY, Coriolis or Inara) into slots, modules, " +
        "blueprints, grades and experimental effects. Module names, class and rating are resolved " +
        "from the game data catalog when available.",
      inputSchema: { slef: z.string().describe("SLEF JSON text") },
    },
    wrap(async ({ slef }: { slef: string }) => {
      const builds = parseSlef(slef);
      const warnings: string[] = [];
      let catalog: Catalog | null = null;
      if (deps.catalog) {
        try {
          catalog = await deps.catalog.get();
        } catch (err) {
          warnings.push(`Catalog unavailable, module names not resolved: ${(err as Error).message}`);
        }
      }
      return {
        builds: builds.map((b) => ({
          ...b,
          modules: b.modules.map((m) => ({ ...m, module: lookup(catalog, m.item) })),
        })),
        warnings,
      };
    }),
  );
}

function lookup(catalog: Catalog | null, item: string) {
  if (!catalog) return null;
  try {
    const [hit] = catalog.module(item);
    return hit ? { name: hit.name, class: hit.class, rating: hit.rating, group: hit.group } : null;
  } catch {
    return null; // armour, cosmetics and some PowerPlay items are not in outfitting.csv
  }
}
```

```ts
import type { InaraConfig } from "../config.js";
import { NotConfiguredError, UserError } from "../errors.js";
import type { TtlCache } from "../http/cache.js";
import type { HttpClient } from "../http/client.js";
import { VERSION } from "../version.js";

export interface InaraProfile {
  commander: string | null;
  inara_user: string | null;
  ranks: Record<string, { rank: number; progress: number }>;
  allegiance: string | null;
  power: string | null;
  role: string | null;
  main_ship: { type: string; name: string | null; ident: string | null } | null;
  squadron: { name: string; rank: string | null; members: number | null; url: string | null } | null;
  inara_url: string | null;
  other_names_found: string[];
  warning?: string;
}

export interface CommunityGoal {
  name: string;
  system: string;
  station: string;
  expires: string;
  tier: number;
  tier_max: number;
  contributors: number;
  completed: boolean;
  objective: string;
  reward: string;
  updated: string;
  description: string;
}

interface InaraEvent {
  eventStatus: number;
  eventStatusText?: string;
  eventData?: unknown;
}
interface InaraResponse {
  header: { eventStatus: number; eventStatusText?: string };
  events: InaraEvent[];
}

type ReadEvent = "getCommanderProfile" | "getCommunityGoalsRecent";

export class InaraClient {
  private queue: Promise<unknown> = Promise.resolve();
  private readonly endpoint: string;
  private readonly now: () => Date;

  constructor(
    private readonly http: HttpClient,
    private readonly cfg: InaraConfig | undefined,
    private readonly cache: TtlCache<unknown>,
    opts: { endpoint?: string; now?: () => Date } = {},
  ) {
    this.endpoint = opts.endpoint ?? "https://inara.cz/inapi/v1/";
    this.now = opts.now ?? (() => new Date());
  }

  async profile(name?: string): Promise<InaraProfile> {
    const ev = (await this.cache.getOrLoad(`profile:${name ?? ""}`, () =>
      this.send("getCommanderProfile", name ? { searchName: name } : {}),
    )) as InaraEvent;
    if (ev.eventStatus === 204) {
      throw new UserError(`Inara: no commander found for "${name ?? this.cfg?.cmdr}"`);
    }
    const d = (ev.eventData ?? {}) as Record<string, unknown>;
    const ship = d.commanderMainShip as
      | { shipType?: string; shipName?: string; shipIdent?: string }
      | undefined;
    const sq = d.commanderSquadron as
      | { SquadronName?: string; SquadronMemberRank?: string; SquadronMembersCount?: number; inaraURL?: string }
      | undefined;
    const ranks = (d.commanderRanksPilot ?? []) as Array<{
      rankName: string;
      rankValue: number;
      rankProgress: number;
    }>;
    const out: InaraProfile = {
      commander: (d.commanderName as string | undefined) ?? null,
      inara_user: (d.userName as string | undefined) ?? null,
      ranks: Object.fromEntries(
        ranks.map((r) => [r.rankName, { rank: r.rankValue, progress: Math.round(r.rankProgress * 100) / 100 }]),
      ),
      allegiance: (d.preferredAllegianceName as string | undefined) ?? null,
      power: (d.preferredPowerName as string | undefined) ?? null,
      role: (d.preferredGameRole as string | undefined) ?? null,
      main_ship: ship?.shipType
        ? { type: ship.shipType, name: ship.shipName || null, ident: ship.shipIdent || null }
        : null,
      squadron: sq?.SquadronName
        ? {
            name: sq.SquadronName,
            rank: sq.SquadronMemberRank ?? null,
            members: sq.SquadronMembersCount ?? null,
            url: sq.inaraURL ?? null,
          }
        : null,
      inara_url: (d.inaraURL as string | undefined) ?? null,
      other_names_found: (d.otherNamesFound as string[] | undefined) ?? [],
    };
    if (ev.eventStatus === 202 && ev.eventStatusText) out.warning = ev.eventStatusText;
    return out;
  }

  async communityGoals(): Promise<CommunityGoal[]> {
    const ev = (await this.cache.getOrLoad("cgs", () =>
      this.send("getCommunityGoalsRecent", []),
    )) as InaraEvent;
    if (ev.eventStatus === 204) return [];
    const goals = (ev.eventData ?? []) as Array<Record<string, unknown>>;
    return goals.map((g) => ({
      name: String(g.communitygoalName ?? ""),
      system: String(g.starsystemName ?? ""),
      station: String(g.stationName ?? ""),
      expires: String(g.goalExpiry ?? ""),
      tier: Number(g.tierReached ?? 0),
      tier_max: Number(g.tierMax ?? 0),
      contributors: Number(g.contributorsNum ?? 0),
      completed: g.isCompleted === true,
      objective: String(g.goalObjectiveText ?? ""),
      reward: String(g.goalRewardText ?? ""),
      updated: String(g.lastUpdate ?? ""),
      description: String(g.goalDescriptionText ?? "").slice(0, 300),
    }));
  }

  // Inara asks clients not to hammer the API, so requests run one at a time.
  private send(eventName: ReadEvent, eventData: unknown): Promise<InaraEvent> {
    const cfg = this.cfg;
    if (!cfg) return Promise.reject(new NotConfiguredError("Inara", ["INARA_API_KEY", "INARA_CMDR"]));
    const run = this.queue.then(async () => {
      const body = {
        header: {
          appName: cfg.appName,
          appVersion: VERSION,
          isBeingDeveloped: cfg.devMode,
          APIkey: cfg.apiKey,
          commanderName: cfg.cmdr,
        },
        events: [
          {
            eventCustomID: 1,
            eventName,
            eventTimestamp: this.now().toISOString().replace(/\.\d{3}Z$/, "Z"),
            eventData,
          },
        ],
      };
      const res = await this.http.json<InaraResponse>(this.endpoint, {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify(body),
      });
      if (res.header?.eventStatus === 400) {
        throw new UserError(
          `Inara rejected the request: ${res.header.eventStatusText ?? "error"}. Check INARA_API_KEY, ` +
            `and that the app name "${cfg.appName}" has been whitelisted by Inara.`,
        );
      }
      const ev = res.events?.[0];
      if (!ev) throw new UserError("Inara returned no event result");
      if (ev.eventStatus === 400) throw new UserError(`Inara error: ${ev.eventStatusText ?? "unknown"}`);
      return ev;
    });
    this.queue = run.catch(() => undefined);
    return run;
  }
}
```

```ts
export const base64url = (buf: Buffer) => buf.toString("base64url");

export function createPkce(): { verifier: string; challenge: string } {
  const verifier = base64url(randomBytes(32));
  // Frontier rejects a padded challenge; base64url output has no padding.
  const challenge = base64url(createHash("sha256").update(verifier).digest());
  return { verifier, challenge };
}
```

```ts
import { chmod, mkdir, readFile, rename, rm, writeFile } from "node:fs/promises";
import path from "node:path";

export interface StoredTokens {
  refresh_token: string;
  access_token: string | null;
  expires_at: number;
  authorized_at: number;
}

export class TokenStore {
  constructor(private readonly file: string) {}

  async load(): Promise<StoredTokens | null> {
    try {
      return JSON.parse(await readFile(this.file, "utf8")) as StoredTokens;
    } catch (err) {
      if ((err as NodeJS.ErrnoException).code === "ENOENT") return null;
      throw err;
    }
  }

  // The refresh token grants account access, so only the user may read the file.
  async save(t: StoredTokens): Promise<void> {
    await mkdir(path.dirname(this.file), { recursive: true });
    const tmp = `${this.file}.${process.pid}.tmp`;
    await writeFile(tmp, JSON.stringify(t), { mode: 0o600 });
    await chmod(tmp, 0o600);
    await rename(tmp, this.file);
  }

  async clear(): Promise<void> {
    await rm(this.file, { force: true });
  }
}
```

```ts
export async function openInBrowser(url: string): Promise<void> {
  // rundll32 avoids cmd.exe treating "&" in the URL as a command separator.
  const [cmd, args] =
    process.platform === "darwin"
      ? ["open", [url]]
      : process.platform === "win32"
        ? ["rundll32", ["url.dll,FileProtocolHandler", url]]
        : ["xdg-open", [url]];
  await new Promise<void>((resolve, reject) => {
    const child = spawn(cmd, args as string[], { detached: true, stdio: "ignore" });
    child.once("error", reject);
    child.once("spawn", () => {
      child.unref();
      resolve();
    });
  });
}
```

```ts
import { createServer, type Server } from "node:http";
import type { AddressInfo } from "node:net";
import type { CapiConfig } from "../config.js";
import { NotConfiguredError, UserError } from "../errors.js";
import type { HttpClient } from "../http/client.js";
import { openInBrowser } from "./browser.js";
import { createPkce, randomState } from "./pkce.js";
import type { StoredTokens, TokenStore } from "./tokens.js";

const DAY = 86_400_000;
const REFRESH_WINDOW = 25 * DAY;

export type LoginState =
  | { state: "logged_out" }
  | { state: "waiting"; url: string; expires_at: string }
  | { state: "logged_in"; authorized_at: string; reauth_by: string }
  | { state: "failed"; error: string };

interface Pending {
  url: string;
  expiresAt: number;
  servers: Server[];
  done: Promise<void>;
}

const PAGE = (msg: string) =>
  `<!doctype html><meta charset="utf-8"><title>ed-mcp</title><p>${msg}</p>`;

export class CapiAuth {
  private pending: Pending | null = null;
  private failure: string | null = null;
  private refreshing: Promise<string> | null = null;
  private readonly authBase: string;
  private readonly openUrl: (url: string) => Promise<void>;
  private readonly now: () => number;
  private readonly loginTimeoutMs: number;

  constructor(
    private readonly http: HttpClient,
    private readonly cfg: CapiConfig | undefined,
    private readonly tokens: TokenStore,
    opts: {
      authBase?: string;
      openUrl?: (url: string) => Promise<void>;
      now?: () => number;
      loginTimeoutMs?: number;
    } = {},
  ) {
    this.authBase = opts.authBase ?? "https://auth.frontierstore.net";
    this.openUrl = opts.openUrl ?? openInBrowser;
    this.now = opts.now ?? Date.now;
    this.loginTimeoutMs = opts.loginTimeoutMs ?? 5 * 60_000;
  }

  async state(): Promise<LoginState> {
    if (this.pending) {
      return {
        state: "waiting",
        url: this.pending.url,
        expires_at: new Date(this.pending.expiresAt).toISOString(),
      };
    }
    if (this.failure) return { state: "failed", error: this.failure };
    const t = await this.tokens.load();
    if (!t || this.now() - t.authorized_at > REFRESH_WINDOW) return { state: "logged_out" };
    return {
      state: "logged_in",
      authorized_at: new Date(t.authorized_at).toISOString(),
      reauth_by: new Date(t.authorized_at + REFRESH_WINDOW).toISOString(),
    };
  }

  async startLogin(): Promise<LoginState> {
    const cfg = this.requireConfig();
    if (this.pending) return this.state();
    this.failure = null;
    const { verifier, challenge } = createPkce();
    const state = randomState();

    let settle!: () => void;
    const done = new Promise<void>((r) => (settle = r));
    const servers: Server[] = [];
    const finish = (error: string | null) => {
      for (const s of servers) s.close();
      clearTimeout(timer);
      this.pending = null;
      this.failure = error;
      settle();
    };

    const handler = createHandler(async (code, gotState) => {
      if (gotState !== state) {
        finish("Login failed: state mismatch");
        return { status: 400, body: PAGE("Login failed: state mismatch. Start again from Claude.") };
      }
      try {
        await this.exchange(cfg, code, verifier, redirectUri);
        finish(null);
        return { status: 200, body: PAGE("Logged in to Frontier. You can close this tab.") };
      } catch (err) {
        finish(`Login failed: ${(err as Error).message}`);
        return { status: 500, body: PAGE("Login failed. Check Claude for details.") };
      }
    });

    // The redirect uses the name "localhost", which may resolve to IPv4 or IPv6.
    const v4 = createServer(handler);
    await new Promise<void>((resolve, reject) => {
      v4.once("error", reject);
      v4.listen(0, "127.0.0.1", resolve);
    });
    servers.push(v4);
    const port = (v4.address() as AddressInfo).port;
    const v6 = createServer(handler);
    await new Promise<void>((resolve) => {
      v6.once("error", () => resolve()); // no IPv6 loopback: IPv4 is enough
      v6.listen(port, "::1", () => {
        servers.push(v6);
        resolve();
      });
    });

    const redirectUri = `http://localhost:${port}/auth`;
    const url = new URL(`${this.authBase}/auth`);
    url.search = new URLSearchParams({
      response_type: "code",
      audience: "frontier,steam,epic",
      scope: "auth capi",
      client_id: cfg.clientId,
      code_challenge: challenge,
      code_challenge_method: "S256",
      state,
      redirect_uri: redirectUri,
    }).toString();

    const timer = setTimeout(() => finish("Login timed out. Call capi_login to try again."), this.loginTimeoutMs);
    timer.unref();
    this.pending = { url: url.href, expiresAt: this.now() + this.loginTimeoutMs, servers, done };
    await this.openUrl(url.href).catch(() => undefined); // the URL is returned for manual opening
    return this.state();
  }

  /** Resolves when the current login attempt finishes (tests and diagnostics). */
  async waitForLogin(): Promise<void> {
    await this.pending?.done;
  }

  async accessToken(): Promise<string> {
    const cfg = this.requireConfig();
    const t = await this.tokens.load();
    if (!t) throw new UserError("Not logged in to Frontier. Call capi_login first.");
    if (this.now() - t.authorized_at > REFRESH_WINDOW) {
      await this.tokens.clear();
      throw new UserError("Frontier login expired (25-day limit). Call capi_login to log in again.");
    }
    if (t.access_token && t.expires_at - 60_000 > this.now()) return t.access_token;
    // Refresh tokens rotate, so concurrent refreshes must share one request.
    this.refreshing ??= this.refresh(cfg, t).finally(() => (this.refreshing = null));
    return this.refreshing;
  }

  /** Forces the next accessToken() call to refresh (after a 401 from CAPI). */
  async invalidate(): Promise<void> {
    const t = await this.tokens.load();
    if (t) await this.tokens.save({ ...t, access_token: null, expires_at: 0 });
  }

  async logout(): Promise<void> {
    await this.tokens.clear();
    this.failure = null;
  }

  private requireConfig(): CapiConfig {
    if (!this.cfg) throw new NotConfiguredError("Frontier CAPI", ["CAPI_CLIENT_ID"]);
    return this.cfg;
  }

  private async exchange(cfg: CapiConfig, code: string, verifier: string, redirectUri: string) {
    const res = await this.token({
      grant_type: "authorization_code",
      client_id: cfg.clientId,
      code_verifier: verifier,
      code,
      redirect_uri: redirectUri,
    });
    await this.tokens.save({
      refresh_token: res.refresh_token,
      access_token: res.access_token,
      expires_at: this.now() + res.expires_in * 1000,
      authorized_at: this.now(),
    });
  }

  private async refresh(cfg: CapiConfig, t: StoredTokens): Promise<string> {
    let res: { access_token: string; refresh_token: string; expires_in: number };
    try {
      res = await this.token({
        grant_type: "refresh_token",
        client_id: cfg.clientId,
        refresh_token: t.refresh_token,
      });
    } catch (err) {
      await this.tokens.clear();
      throw new UserError(
        `Frontier refused to refresh the login (${(err as Error).message}). Call capi_login to log in again.`,
      );
    }
    await this.tokens.save({
      refresh_token: res.refresh_token,
      access_token: res.access_token,
      expires_at: this.now() + res.expires_in * 1000,
      authorized_at: t.authorized_at,
    });
    return res.access_token;
  }

  private token(form: Record<string, string>) {
    return this.http.json<{ access_token: string; refresh_token: string; expires_in: number }>(
      `${this.authBase}/token`,
      {
        method: "POST",
        headers: { "content-type": "application/x-www-form-urlencoded" },
        body: new URLSearchParams(form).toString(),
      },
    );
  }
}

function createHandler(
  onCallback: (code: string, state: string | null) => Promise<{ status: number; body: string }>,
) {
  return (req: import("node:http").IncomingMessage, res: import("node:http").ServerResponse) => {
    const url = new URL(req.url ?? "/", "http://localhost");
    const code = url.searchParams.get("code");
    if (url.pathname !== "/auth" || !code) {
      res.writeHead(404).end();
      return;
    }
    void onCallback(code, url.searchParams.get("state")).then(({ status, body }) => {
      res.writeHead(status, { "content-type": "text/html; charset=utf-8" }).end(body);
    });
  };
}
```

```ts
    opts: { base?: string } = {},
  ) {
    this.base = opts.base ?? "https://companion.orerve.net";
  }

  async profile(): Promise<CapiProfile> {
    const raw = (await this.cache.getOrLoad("profile", () => this.get("/profile"))) as {
      commander: { name: string; credits: number; docked: boolean; onfoot?: boolean };
      lastSystem?: { name?: string };
      lastStarport?: { name?: string };
      ship?: RawShip;
      ships?: Record<string, RawShip> | RawShip[];
    };
    const ships = Array.isArray(raw.ships) ? raw.ships : Object.values(raw.ships ?? {});
    return {
      commander: {
        name: raw.commander.name,
        credits: raw.commander.credits,
        docked: raw.commander.docked,
        on_foot: raw.commander.onfoot ?? false,
      },
      system: raw.lastSystem?.name ?? null,
      // lastStarport is stale when not docked.
      station: raw.commander.docked ? (raw.lastStarport?.name ?? null) : null,
      ship: raw.ship ? mapShip(raw.ship) : null,
      ships: ships.map((s) => ({
        id: s.id,
        type: s.name,
        name: s.shipName || null,
        ident: s.shipID || null,
        system: s.starsystem?.name ?? null,
        station: s.station?.name ?? null,
      })),
    };
  }

  private async get(path: string): Promise<unknown> {
    for (let attempt = 0; attempt < 2; attempt++) {
      const token = await this.auth.accessToken();
      const res = await this.http.request(`${this.base}${path}`, {
        headers: { authorization: `Bearer ${token}` },
      });
      if (res.status === 401 && attempt === 0) {
        await this.auth.invalidate();
        continue;
      }
      if (res.status === 401) throw new UserError("Frontier rejected the login. Call capi_login again.");
      if (!res.ok) throw new UserError(`Frontier CAPI returned HTTP ${res.status}`);
      return res.json();
    }
    throw new UserError("Frontier CAPI request failed");
  }
}

function mapShip(s: RawShip): NonNullable<CapiProfile["ship"]> {
  return {
    id: s.id,
    type: s.name,
    name: s.shipName || null,
    ident: s.shipID || null,
    value: s.value?.total ?? null,
    modules: Object.entries(s.modules ?? {}).map(([slot, m]) => {
      const specials = m.specialModifications;
      const experimental =
        specials && !Array.isArray(specials) ? (Object.keys(specials)[0] ?? null) : null;
      return {
        slot,
        item: (m.module?.name ?? "").toLowerCase(),
        name: m.module?.locName ?? null,
        on: m.module?.on ?? null,
        engineering: m.engineer?.recipeName
          ? {
              blueprint: m.engineer.recipeName,
              grade: m.engineer.recipeLevel ?? 0,
              engineer: m.engineer.engineerName ?? null,
              experimental,
            }
          : null,
      };
    }),
  };
}
```
