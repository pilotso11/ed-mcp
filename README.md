# inara-mcp

An MCP server that gives Claude tools for Elite Dangerous build planning. It
reads commander data from Inara, EDSM and Frontier's Companion API, looks up
stations and routes on Spansh, and keeps build plans on your machine.

Status: in development. See [the design](docs/superpowers/specs/2026-10-11-inara-mcp-design.md).

Not affiliated with Frontier Developments, Inara, EDSM or Spansh.
