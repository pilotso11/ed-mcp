# Catalog data sources

Committed here:

| File | Source | Licence |
|---|---|---|
| engineers.json | EliteDangerousCore `EliteDangerous/FrontierData/Items/Engineers.cs` (master) | Apache-2.0, see NOTICE |
| groups.json | Generated by `npm run catalog:statics` from coriolis-data module files joined with FDevIDs outfitting.csv. Lists Coriolis group codes and module names only | identifiers, no data copied |
| ships.json | Generated by `npm run catalog:statics` from coriolis-data ship files (pad class) joined with FDevIDs shipyard.csv (symbol). Ship symbols and pad sizes only | identifiers, no data copied |

Downloaded at runtime to the user's cache, never committed or bundled:

| Key | URL |
|---|---|
| blueprints | https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/blueprints.json |
| specials | https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/specials.json |
| modifications | https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/modules.json |
| materials | https://raw.githubusercontent.com/EDCD/FDevIDs/master/material.csv |
| outfitting | https://raw.githubusercontent.com/EDCD/FDevIDs/master/outfitting.csv |
| actions | https://raw.githubusercontent.com/EDCD/coriolis-data/develop/modifications/modifierActions.json |

These repositories do not grant an open licence for their data, which is
Frontier Developments' intellectual property. Downloading them to the user's
machine mirrors how the Coriolis and EDSY web apps use them.
